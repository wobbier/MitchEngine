## Color

Linear RGBA in [0, 1] — drawn with a color row in the inspector.

- `(constructor)(System.Single,System.Single,System.Single,System.Single)` (method): A color from linear channels (alpha defaults to opaque).
- `a` (field): The channels, linear (alpha is coverage, 0..1).
- `b` (field): The channels, linear (alpha is coverage, 0..1).
- `Black` (field): (0, 0, 0, 1).
- `Blue` (field): Pure blue.
- `Clear` (field): Transparent black (0, 0, 0, 0).
- `FromHex(System.String)` (method): "#RRGGBB" or "#RRGGBBAA" (sRGB) as a linear color.
- `FromHsv(System.Single,System.Single,System.Single,System.Single)` (method): Hue 0..360, saturation and value 0..1 (in the sRGB space hex codes use).
- `g` (field): The channels, linear (alpha is coverage, 0..1).
- `Green` (field): Pure green.
- `Lerp(Color,Color,System.Single)` (method): Linear interpolation of every channel (t clamped to 0..1).
- `LinearToSrgb(System.Single)` (method): Linear to sRGB-encoded, per channel (the inverse of SrgbToLinear).
- `op_Addition(Color,Color)` (method): Channel-wise sum.
- `op_Multiply(Color,Color)` (method): Channel-wise product (tinting).
- `op_Multiply(Color,System.Single)` (method): Scales every channel.
- `r` (field): The channels, linear (alpha is coverage, 0..1).
- `Red` (field): Pure red.
- `SrgbToLinear(System.Single)` (method): sRGB-encoded (what color pickers and hex codes are) to the engine's linear, and back.
- `ToHex` (method): "#RRGGBBAA" (sRGB), the inverse of FromHex.
- `ToString` (method): "{r, g, b, a}".
- `White` (field): (1, 1, 1, 1).

## Mathf

Float math helpers (a thin layer over System.MathF, plus game-friendly extras).

- `Abs(System.Single)` (method): The absolute value.
- `Atan2(System.Single,System.Single)` (method): The angle of (x, y) from +X, in radians (-pi..pi).
- `Clamp(System.Single,System.Single,System.Single)` (method): The value kept within [min, max].
- `Clamp01(System.Single)` (method): The value kept within [0, 1].
- `Cos(System.Single)` (method): The cosine of radians.
- `Damp(System.Single,System.Single,System.Single,System.Single)` (method): Frame-rate independent smoothing: moves current towards target, covering most of the way in about "halfLife * 4" seconds.
- `Damp(Vector3,Vector3,System.Single,System.Single)` (method): Frame-rate independent smoothing of a vector (see the float Damp).
- `Deg2Rad` (field): Multiply degrees by it for radians.
- `Lerp(System.Single,System.Single,System.Single)` (method): Linear interpolation: a at t = 0, b at t = 1 (t isn't clamped).
- `Lerp(Vector3,Vector3,System.Single)` (method): Linear interpolation of vectors (t isn't clamped).
- `Max(System.Single,System.Single)` (method): The larger value.
- `Min(System.Single,System.Single)` (method): The smaller value.
- `PI` (field): Pi.
- `Rad2Deg` (field): Multiply radians by it for degrees.
- `Sin(System.Double)` (method): The sine of radians.
- `Sin(System.Single)` (method): The sine of radians.
- `Sqrt(System.Single)` (method): The square root.

## Matrix4x4

A 4x4 transform, column-major like the engine's (glm): m[column, row], translation in column 3. Points are columns: Matrix * point.

- `GetTranslation` (method): The translation (column 3).
- `Identity` (field): The identity matrix.
- `Inverse` (method): The general inverse (Gauss-Jordan); Identity when the matrix is singular.
- `Item(System.Int32,System.Int32)` (property): Element at row r, column c.
- `m00` (field): Column 0, then 1, 2, 3.
- `m01` (field): Column 1.
- `m02` (field): Column 2.
- `m03` (field): Column 3 (the translation, and the projective row 3).
- `m10` (field): Column 0, then 1, 2, 3.
- `m11` (field): Column 1.
- `m12` (field): Column 2.
- `m13` (field): Column 3 (the translation, and the projective row 3).
- `m20` (field): Column 0, then 1, 2, 3.
- `m21` (field): Column 1.
- `m22` (field): Column 2.
- `m23` (field): Column 3 (the translation, and the projective row 3).
- `m30` (field): Column 0, then 1, 2, 3.
- `m31` (field): Column 1.
- `m32` (field): Column 2.
- `m33` (field): Column 3 (the translation, and the projective row 3).
- `MultiplyPoint(Vector3)` (method): A point (w = 1): translation applies.
- `MultiplyVector(Vector3)` (method): A direction (w = 0): no translation.
- `op_Multiply(Matrix4x4,Matrix4x4)` (method): The matrix product: applies b, then a.
- `Rotate(Quaternion)` (method): A rotation matrix.
- `Scale(Vector3)` (method): A scale matrix.
- `ToString` (method): The four rows, separated by semicolons.
- `Translate(Vector3)` (method): A translation matrix.
- `Transposed` (method): The transpose.
- `TRS(Vector3,Quaternion,Vector3)` (method): Translation * Rotation * Scale: what a Transform's local matrix is.

## Quaternion

xyzw, identity = (0, 0, 0, 1) — matching the engine's Quaternion layout.

- `(constructor)(System.Single,System.Single,System.Single,System.Single)` (method): A quaternion from its components (not normalized for you).
- `Angle(Quaternion,Quaternion)` (method): The angle between two rotations, in degrees.
- `AngleAxis(System.Single,Vector3)` (method): A rotation of `degrees` about `axis` (normalized here).
- `Conjugate` (method): The conjugate (the inverse, for a unit quaternion).
- `Dot(Quaternion,Quaternion)` (method): The 4D dot product (1 or -1 for the same rotation).
- `Euler(System.Single,System.Single,System.Single)` (method): A rotation from Euler angles in degrees (as Euler(Vector3) does).
- `Euler(Vector3)` (method): Euler angles in degrees, the engine's convention (Transform.Rotation; glm's quat(vec3)).
- `Identity` (field): No rotation (0, 0, 0, 1).
- `Inverse` (method): The inverse rotation (Identity for a zero quaternion).
- `Length` (method): The quaternion's length (1 for a rotation).
- `LookRotation(Vector3)` (method): The rotation that looks along forward, with +Y as up.
- `LookRotation(Vector3,Vector3)` (method): Faces `forward` (+Z is the engine's forward) with `up` as close to up as it can be.
- `Normalize` (method): Scales this quaternion to unit length.
- `Normalized` (method): A unit-length copy.
- `op_Multiply(Quaternion,Quaternion)` (method): a then b: (a * b) rotates by b first, then by a (the glm / Unity order).
- `op_Multiply(Quaternion,Vector3)` (method): Rotates a vector.
- `Slerp(Quaternion,Quaternion,System.Single)` (method): The shortest-path spherical blend.
- `ToEuler` (method): Back to Euler degrees (glm::eulerAngles).
- `ToString` (method): "{x, y, z, w}".
- `w` (field): The components (x, y, z vector part, w scalar part).
- `x` (field): The components (x, y, z vector part, w scalar part).
- `y` (field): The components (x, y, z vector part, w scalar part).
- `z` (field): The components (x, y, z vector part, w scalar part).

## AI.Perception

What an AI noticed: sight (range, field of view, line of sight through physics) and hearing (Noise.Make), with a memory of where it last saw or heard its target.

- `EyeHeight` (field): Above the entity's position
- `FieldOfView` (field): Degrees, full cone
- `HearingScale` (field): Multiplies each noise's radius
- `InCone(Vector3,Vector3,Vector3,System.Single,System.Single)` (method): Within range and inside the view cone (ignoring height), from an eye looking along forward.
- `Update(ScriptCore.Entity,ScriptCore.Entity,System.Single)` (method): Looks for target from self and listens for noises; call once per update.

## AudioSource

The entity's AudioSource (CS-5 b): play, stop, pause; fields (Volume, Pitch, Loop, Bus...) through GetField / SetField like any component.

## Camera

- `FieldOfView` (property): CS-5 e: projection. FieldOfView is the vertical angle in degrees (the engine's Zoom field).
- `OrthographicSize` (property): Half the view height in metres, for an orthographic camera.
- `OutputSize` (property): The pixels it renders (its output size times its viewport rect).
- `RenderScale` (property): Render scaling (LOOK-S1, ME-275): the scene renders at OutputSize * RenderScale (0.1..1) and is stretched back up with Upscale. Dynamic resolution lowers the scale while the GPU is over budget. The player's Graphics.RenderScale setting multiplies on top.
- `SetClipPlane(Vector3,Vector3)` (method): Hides everything behind a world-space plane (the side the normal points away from), as if the near plane were that surface. A camera looking out of a portal or a mirror uses the exit surface. Ignored while the camera is in front of the plane.
- `TargetTexture` (property): Render texture: renders into this .rendertexture asset (a project path such as "Assets/Textures/Feed.rendertexture"), at the asset's size, instead of to the screen. Materials show the image by naming the same asset in a texture slot. Empty renders normally.
- `UpdateInterval` (property): Renders every Nth frame (1 = every frame); the texture keeps its last image in between.
- `WorldToScreen(Vector3)` (method): Where a world point lands on screen: x, y in pixels from the top left, z its distance in front of the camera (negative behind it).

## CaptionLines

The caption queue itself: no engine calls, so tests can drive it with their own clock.

- `Add(System.String,System.String,System.Single,System.Single)` (method): Returns how long the line shows.
- `ReadingSeconds(System.String)` (method): About as long as it takes to read: 1.5 s plus 60 ms a character, 2 to 8 s.

## Captions

PLAY-7: subtitles and closed captions in the stock caption strip (Engine/Assets/UI/Captions/ Captions.rml, a UIDocument the scene adds; it binds the "captions" model). The player's Accessibility settings decide whether they show, whether speakers are named, their size and their backdrop: Captions.Say("Guard", "Who goes there?"); // a line of speech, for as long as it takes to read Captions.Sound("door creaks"); // a sound, shown as [door creaks] Up to three lines show at once, newest last; each goes after its time (real time, so a paused game doesn't hold them forever).

- `Refresh` (method): Drops the lines whose time is up and writes the model (Say and Sound schedule it).

## CharacterController

The capsule character moved by the physics mover (Engine/Docs/Physics.md).

- `Move(Vector3)` (method): A displacement added on the next physics step.
- `SetMoveInput(Vector3)` (method): Desired horizontal direction in world space; length <= 1 scales the speed. Kept until changed.
- `Teleport(Vector3,Vector3)` (method): Moves the character instantly, turned to face forward (flattened: characters stay upright). Clears its velocity; set Velocity afterwards to keep moving.

## CharacterController2D

The platformer capsule moved by Box2D's mover in the XY plane (Engine/Docs/Physics.md): runs along slopes, jumps with a short coyote time, falls with gravity.

- `Jump` (method): Jumps when on the ground, or within the controller's CoyoteTime of leaving it.
- `SetMoveInput(System.Single)` (method): Desired horizontal direction in [-1, 1]. Kept until changed.
- `Teleport(Vector2)` (method): Moves the character instantly; clears its velocity.

## Dialogue.DialogueRunner

Steps through a DialogueScript: Start(node), then Continue() past lines and Choose(i) at choices until End. Variables live in a dictionary that can be shared between runners (what the player said earlier). Text goes through Translate (localization keys = the source text) and then {$var}.

- `Translate` (field): Localizes a line or option (default: the engine's Loc, untranslated outside the engine).

## Dialogue.DialogueScript

GAME-8: conversations as text (.dialogue files), in the spirit of Yarn: title: Gate --- Guard: Halt! Who goes there? -> A friend. <<set $trusted = true>> Guard: Then pass, friend. -> None of your business. <<if not $trusted>> Guard: Then you stay out. <<jump Refused>> <<if $trusted>> Guard: Mind the stairs, {$name}. <<else>> Guard: Move along. <<endif>> <<event open-gate>> === A node is "title: Name", "---", its lines, "===". A line is "Speaker: text" (or just text); a run of "-> text" lines is a choice, each followed by its indented body; a trailing "<<if expr>>" on an option shows it only when true. Commands: <<jump Node>>, <<set $var = expr>>, <<if expr>> / <<elseif expr>> / <<else>> / <<endif>>, <<event name args...>> (raised for the game), <<stop>>. "//" starts a comment. Text can show variables: {$name}. Lines and options are localization keys (DialogueRunner translates them before interpolating).


## Dialogue.DialogueStep

- `Choice` (field): Choices lists the options; Choose(i) picks one
- `Line` (field): Speaker / Text show a line; Continue() moves on

## Dialogue.DialogueView

Shows a DialogueRunner through a UI model ("dialogue": visible, speaker, text, choosing, choice0..3 / has0..3) and answers its events (dialogue_continue, dialogue_choose_0..3). The stock Engine/Assets/UI/Dialogue/Dialogue.rml binds it; a project can bring its own document with the same model. Call Update() every frame while it's up.

- `Update` (method): Applies clicks from the document; true while the conversation runs.

- `Number(System.Object)` (method): An unset variable is false, which counts as 0: <<set $visits = $visits + 1>> just works.

## Engine

Low-level engine access: logging and time. Most scripts use Debug, Time and the typed APIs instead.

- `GetTime` (method): Seconds since the engine started.
- `Log(System.String,System.String,System.String,System.Int32)` (method): Logs a message with the caller's file, line and member (Debug.Log calls it).
- `Utf8(System.String,System.Span{System.Byte})` (method): Encodes a string NUL-terminated into the caller's stack buffer for an engine call; only strings that don't fit allocate.
- `Utf8StackSize` (field): The stack buffer for Utf8, in bytes: fixed (byte* p = Engine.Utf8(name, stackalloc byte[Engine.Utf8StackSize])) _api.X(p); allocates nothing for strings that fit (ME-300).

## Entity

struct because it's mapped to the engine EntityID struct. don't fuckin add anything to this <3 or at least update it to reflect it

- `(constructor)(System.UInt32,System.UInt32)` (method): A handle from its index and generation (scripts get these from the engine, not by hand).
- `Active` (property): Whether the entity is active (an inactive entity and its children don't update or draw).
- `AddComponent(System.String)` (method): Adds an engine component by registry name ("Light", "Rigidbody").
- `AddComponent1` (method): Adds a component of type T and returns it.
- `Children` (property): Its direct children (CS-5 h).
- `Destroy` (method): Destroys the entity and its children at the end of the frame.
- `Equals(ScriptCore.Entity)` (method): Same entity: index and generation match.
- `Equals(System.Object)` (method): Same entity.
- `Generation` (field): The slot's generation: a handle to a destroyed entity stops matching when the slot is reused.
- `GetComponent1` (method): The entity's component of type T, or null.
- `GetField1(System.String,System.String,0)` (method): Any field of any component by name, including ones without a C# wrapper: GetField<float>("Light", "Intensity"). Paths can go deeper ("Settings.Radius", "Color.0"); a missing component or field returns the fallback.
- `GetFieldJson(System.String,System.String)` (method): A component field as JSON text, or null when it's missing.
- `GetHashCode` (method): A hash of index and generation.
- `GetScript1` (method): The entity's script when it is (or implements) T: GetScript<Door>(), GetScript<IHealth>(). Null when it has none. A scan of the live scripts; fine for events, not for every entity every frame.
- `Guid` (property): The scene GUID (the 16-hex string scenes and EntityRef store), "" for a dead entity.
- `HasComponent(System.String)` (method): Any registered component by name ("Light", "ParticleSystem", "AudioSource"...), wrapped in C# or not; its fields are reachable through Component.GetField / SetField.
- `HasComponent1` (method): Whether the entity has a component of type T.
- `Index` (field): Mirrors the engine's 8-byte EntityID: slot index + generation (0 = null).
- `IsAlive` (property): Whether the entity still exists.
- `Layer` (property): The physics / filtering layer, 0..31 (Project Settings names them).
- `Name` (property): The entity's name.
- `Null` (field): {0, 0}
- `op_Equality(ScriptCore.Entity,ScriptCore.Entity)` (method): Same entity.
- `op_Implicit(ScriptCore.Entity)~System.Boolean` (method): what is life?
- `op_Inequality(ScriptCore.Entity,ScriptCore.Entity)` (method): Different entities.
- `SetField1(System.String,System.String,0)` (method): Sets a field of any component by name (see GetField); false when the component or field is missing.
- `SetFieldJson(System.String,System.String,System.String)` (method): Sets a component field from JSON text; false when the component or field is missing.
- `ToString` (method): "Entity(index:generation)".
- `Transform` (property): The entity's Transform.
- `TryGetComponent1(0@)` (method): The component of type T and true, or null and false.

## EntityRef

A saveable reference to a scene entity: stores the entity's scene GUID (the 16-hex string .lvl files use), so it survives save/load and script hot reloads. Resolve() finds the live entity in the current world. The inspector draws it as an entity row (drag an entity in).


## ExecutionOrderAttribute

Update order among scripts: lower runs first (default 0) in OnStart, OnFixedUpdate, OnUpdate and OnLateUpdate; scripts with the same order run in the order they started. [ExecutionOrder(-100)] public class InputReader : Script { ... }


## FieldReflection

- `WithSaved(System.Type)` (method): Of(type) plus every [Save] field the inspector doesn't show (non-public or hidden): what a save game stores, and what loading one restores.

## ForceMode

- `Acceleration` (field): Continuous, ignores mass
- `Force` (field): Continuous, mass dependent
- `Impulse` (field): Instant, mass dependent
- `VelocityChange` (field): Instant, ignores mass

## FormerNameAttribute

Keeps saved data loading after a rename. On a script class, scenes that name the old class create this one (and are saved with the new name); on a field, a value saved under the old name is read into it. [FormerName("EnemyBrain")] public class EnemyAI : Script { [FormerName("speed")] public float MoveSpeed; }

## Generation.FieldDescriptor

One persisted field: its name, kind and boxed accessors (generated static lambdas, not reflection, so collectible script assemblies stay unloadable and AOT stays possible).

- `TypeName` (property): Display name of the field's type ("float", "Vector3", "My.Enum").

## Generation.FieldKind

What a generated field is, for save/net/inspector/UI layers that need to walk fields without reflection.


## Generation.GenerateSchemaAttribute

Opts a partial class into the CS-9 source generator: a static TypeSchema, SaveFields/LoadFields JSON serializers and a SchemaRegistry entry are generated at compile time, with no reflection. The class must be a non-generic, non-nested partial class; unsupported fields are skipped with a MEGEN002 warning.


## Generation.SchemaRegistry

Generated module initializers register each schema here, so lookups by type need no reflection. Keys are held weakly: a hot-reloaded script assembly's types must stay collectible, or the old AssemblyLoadContext could never unload.


## Generation.TypeSchema

A type's generated schema. Hash is a stable FNV-1a over the names and kinds, so two builds agree on it exactly when their fields agree (net handshakes, save versioning).

## IGameScript

What the engine calls on a script. Derive from Script, which implements it, rather than implementing this directly.

- `OnCollisionEnter(ScriptCore.Collision)` (method): Physics (3D and 2D), while the game runs: a contact with another collider starts.
- `OnCollisionExit(ScriptCore.Collision)` (method): A contact with another collider ends.
- `OnDestroy` (method): When the script's entity is destroyed, or the game stops.

- `OnEvent(System.Action{ScriptCore.SequenceEvent})` (method): This player's markers and notifications (GAME-4). Like Script.On, a script's handler goes when it's destroyed (and on a hot reload); Dispose the result to stop sooner.
- `Play(System.String,System.Boolean)` (method): Names are configured in the Sequencer's Clips tab. False leaves the current playback intact.

## SequenceEvent

A Sequencer marker crossed during playback (Kind Marker: Name, Payload and Number as authored), or a playback notification (Name is the sequence's). Markers go to the marker's receiver object, notifications to the player; both are also published on the EventBus. Receiver is Entity.Null for a marker whose binding slot isn't bound.

- `(constructor)(ScriptCore.Entity,ScriptCore.Entity,ScriptCore.SequenceEventKind,System.String,System.String,System.Single,System.Int32,System.String)` (method): A Sequencer marker crossed during playback (Kind Marker: Name, Payload and Number as authored), or a playback notification (Name is the sequence's). Markers go to the marker's receiver object, notifications to the player; both are also published on the EventBus. Receiver is Entity.Null for a marker whose binding slot isn't bound.

## ServerRpcAttribute

Runs on the server: declare `[ServerRpc] partial void Name(args);` and write `On{Name}(args)`.


## Settings

- `GetBindingDisplay(System.String,System.Int32)` (method): What a prompt shows for a binding: "Space", "Gamepad South", "W/A/S/D".
- `GetFloat(System.String,System.Single)` (method): The game's own values, stored as Game.<key>.
- `GetJson(System.String)` (method): Any key as JSON text ("null" when it isn't set).
- `GetVolume(ScriptCore.AudioBus)` (method): The player's volume for a bus, 0..1 (it scales the project's mix).
- `HighContrast` (property): PLAY-7: the high-contrast class on every UI document.
- `Language` (property): A string table code ("es" reads Assets/UI/Strings/es.json); "" = none.
- `Quality` (property): "" = no player caps; else one of QualityPresets.
- `Rebind(System.String,System.Int32,System.String,System.String)` (method): Binds binding `binding` of an action (or a composite part: "Up", "Negative"...) to a control path ("Keyboard/J", "Gamepad/North"). False for an unknown action, binding or control.
- `ReduceMotion` (property): No camera shake (the kit's CameraImpulse honours it); games read it for their own sway.
- `Reset` (method): Every setting back to its default, rebinds included.
- `Save` (method): Writes the settings now. False when the run keeps them in memory (automated runs).
- `SetJson(System.String,System.String)` (method): False (and an error in the log) when the key or the value is rejected.
- `SubtitleBackground` (property): The caption backdrop's opacity, 0..1.
- `Subtitles` (property): Captions and subtitles (Captions.Say / Sound), on by default.
- `SubtitleSize` (property): Caption text scale, 0.75..2.
- `TextScale` (property): The UI's text scale, 0.5..3.
- `ToggleHolds` (property): PLAY-7: input actions marked Toggle (sprint, crouch) latch on a press instead of being held.

## SimulatedInput

- `Hold(ScriptCore.KeyCode,System.Single)` (method): Holds the key for the given game time (at least one frame), then releases it.
- `Play(System.Collections.Generic.IReadOnlyList{ScriptCore.SimulatedInput.Event})` (method): Applies each event once the recording's game time reaches it. Keys still held at the end stay held (end a recording with its releases, or call Input.ReleaseSimulated).
- `Record` (method): Records the real keyboard's key changes until disposed, then logs the recording.

## SpaceAttribute

Vertical spacing above the field (defaults to half a line).

- `(constructor)(System.Single)` (method): Space above the field (0: half a line).
- `Height` (field): The gap in pixels (0: half a line).

## Spline

- `GetPath` (method): The curve now, in world space. Points go through the entity's world position, rotation and scale (the product of the local scales up the hierarchy).
- `Points` (property): Local positions the curve passes through, in order.

## SplineMath

GAME-2: the Spline component's curve math (C++ SplineMath in Components/Gameplay/Spline.cpp, kept in step): a uniform Catmull-Rom curve through every point. Open curves extrapolate their end tangents, closed ones wrap; t runs 0..1 over the whole curve, each segment an equal share.

- `Derivative(System.Collections.Generic.IReadOnlyList{Vector3},System.Boolean,System.Single)` (method): dP/dt (t over the whole curve).

## SplinePath

A spline's curve in world space at one moment: build it once (Spline.GetPath()) and ask it several questions, rather than reading the component for each.

- `GetNearestT(Vector3)` (method): The t of the curve's point nearest a world position.
- `GetTAtDistance(System.Single)` (method): The t a distance along the curve reaches (closed curves wrap; open ones clamp).

## SpriteRenderer

The entity's SpriteRenderer (LOOK-S2): which sprite of its sheet it shows, flips, the tint and the draw order. Animators with flipbook clips set the sprite themselves while they play.

- `Color` (property): sRGB tint (rgb) and opacity (a).
- `SetSprite(System.String,System.String)` (method): A sprite from another sheet (a .spritesheet path); "" keeps the current sheet.
- `Sprite` (property): The sprite's name in the sheet.
- `Texture` (property): A plain image instead of (or under) the sheet's.

## TextRenderer

The entity's TextRenderer (LOOK-S12): world-space text for signs, labels and damage numbers.

- `Color` (property): sRGB colour (rgb) and opacity (a).

## Tilemap

The entity's Tilemap (LOOK-S5): cells by palette index (-1 = empty). A TilemapCollider2D on the entity follows the changes on the next physics step.

- `WorldToCell(Vector3)` (method): The cell a world point lies in (on the tilemap's plane).

## Time

- `DeltaTime` (property): Scaled game time this frame (0 while paused).
- `FixedDeltaTime` (property): The fixed simulation step (OnFixedUpdate).
- `RealTime` (property): Seconds since scripting started (wall clock).
- `UnscaledDeltaTime` (property): Real seconds this frame, ignoring pause and time scale.

## TooltipAttribute

Hover text on the field's row.

- `(constructor)(System.String)` (method): Hover text for the field.
- `Text` (field): The hover text.

## Transform

- `LookDirection(Vector3,Vector3)` (method): Turns to face a world direction, with up as close to the given up as possible.
- `Parent` (property): The parent entity (Entity.Null at the scene root); setting it keeps the world pose.
- `Rotate(Vector3)` (method): Rotates by degrees about the local axes using quaternion composition.

## Tween

- `Float(System.Single,System.Single,System.Single,System.Action{System.Single},ScriptCore.Ease,ScriptCore.Script)` (method): Calls setter with from..to over seconds of game time (eased); the last call is exactly `to`.
- `Move(ScriptCore.Transform,Vector3,System.Single,ScriptCore.Ease,ScriptCore.Script)` (method): Moves a transform's position to `to`.

## UI

- `Show(System.String)` (method): The UIDocument on the entity with this name (a menu such as the stock options menu, Assets/UI/Options/Options.rml). False when no UIDocument entity has that name.

## UIModel

- `On(System.String)` (method): Registers a data-event name the document can raise (data-event-click="name").
- `PollEvent` (method): The oldest queued event name, or "" when none are waiting.

## UpscaleFilter

How a camera's scaled-down image is stretched to its output.

- `Pixel` (field): Whole-number blocks, for pixel art
- `Sharp` (field): Catmull-Rom plus contrast-adaptive sharpening

## WaitForSeconds

The yield instructions coroutines understand (plus null = the next frame, and a nested IEnumerator).


## World

The scene: create, find and spawn entities, and load scenes.

- `CreateEntity(System.String)` (method): A new entity with a Transform, at the scene root.
- `Find(System.String)` (method): The first entity with that name, or Entity.Null.
- `GetSceneState(System.Int32)` (method): An additive scene's state.
- `GetTransformByName(System.String)` (method): The Transform of the first entity with that name, or null.
- `Instantiate(System.String,ScriptCore.Entity)` (method): Spawns a prefab (optionally under a parent) and returns its root entity.
- `IsLoadingScene` (property): Whether a LoadSceneAsync is running.
- `LoadProgress` (property): 0..1 while LoadSceneAsync runs; 1 otherwise.
- `LoadScene(System.String)` (method): Loads a scene at the end of this frame.
- `LoadSceneAdditive(System.String,System.Boolean)` (method): Loads a scene on top of this one (a streamed level chunk, a shared lighting scene) and returns its id. Async (the default) reads it in the background and adds it at the start of a later frame: watch SceneState. Its entities unload together and go when the main scene changes.
- `LoadSceneAsync(System.String,System.String)` (method): Loads a scene in the background under a loading screen (PLAY-5): the current scene keeps running while the file is read, and the screen stays up until the new scene's assets have loaded. loadingScreen: "" = the project's (Assets/UI/Loading/Loading.rml by default), "none" = no screen. False when the scene doesn't exist or a load is already running.
- `UnloadScene(System.Int32)` (method): Unloads an additive scene and its entities; false for an unknown id.

## Vector3

A 3D vector in metres, +Y up (the engine's coordinates: +X right, +Z forward).

- `(constructor)(System.Single,System.Single,System.Single)` (method): A vector from its components.
- `(constructor)(Vector3)` (method): A copy of another vector.
- `Cross(Vector3,Vector3)` (method): The cross product (right-handed).
- `Distance(Vector3,Vector3)` (method): The distance between two points.
- `Dot(Vector3,Vector3)` (method): The dot product.
- `Forward` (property): +Z (0, 0, 1).
- `Length` (method): The vector's length.
- `LengthSquared` (method): The squared length (cheaper than Length for comparisons).
- `Lerp(Vector3,Vector3,System.Single)` (method): Linear interpolation: a at t = 0, b at t = 1 (t isn't clamped).
- `Normalized` (method): Unit length, or zero for a zero vector.
- `One` (property): (1, 1, 1).
- `op_Addition(Vector3,Vector3)` (method): Component-wise sum.
- `op_Division(Vector3,System.Single)` (method): Divides every component.
- `op_Multiply(System.Single,Vector3)` (method): Scales every component.
- `op_Multiply(Vector3,System.Single)` (method): Scales every component.
- `op_Subtraction(Vector3,Vector3)` (method): Component-wise difference.
- `op_UnaryNegation(Vector3)` (method): The opposite vector.
- `Right` (property): +X (1, 0, 0).
- `ToString` (method): "{x, y, z}".

- `x` (field): The components.
- `y` (field): The components.
- `z` (field): The components.
